# MCN 出海内容管理平台

帮助内容运营团队把国内平台（B站等）的视频和图文素材，搬运并发布到海外社交媒体（Twitter/X），同时管理多个海外账号和追踪数据表现的一站式工作台。

---

## 核心功能

### 内容采集

- 输入 B站创作者的主页链接或 UID，自动抓取该创作者的全部公开作品信息（视频、封面、标题、描述、标签、播放量等）
- 支持粘贴单个视频链接，快速采集单条内容
- 提供"只采集信息不下载文件"和"采集并下载"两种模式——先浏览再决定下载哪些
- 采集到的视频自动合并音画轨道，直接得到可用的完整视频文件

### 素材管理

- 所有采集到的内容和手动上传的文件，统一存放在素材库中
- 素材按来源平台（B站 / 用户上传）和创作者自动分类归档
- 支持在线预览视频和图片，无需下载到本地
- 可创建自定义文件夹，手动上传自己的素材
- 支持批量删除、整理

### 发布到 Twitter/X

- 选择已添加的 Twitter 账号，直接在平台内编写推文并发布
- 支持纯文字、图片（最多 4 张）、视频、GIF 等多种推文类型
- 可选择"立即发布"或"定时发布"
- 发布队列管理：把多条内容排入队列，平台按计划自动逐条发出
- 队列支持暂停、恢复、调整顺序、重试失败任务
- 发布历史完整记录，每条推文的成功/失败状态一目了然

### 多账号管理

- 批量导入 Twitter 账号，支持多种格式的账号信息粘贴导入
- 每个账号可一键验证登录状态（正常 / 异常 / 未验证）
- 账号按"发布用"和"监控用"分开管理，职责清晰

### 代理 IP 隔离

- 每个 Twitter 账号绑定独立的网络代理，确保不同账号之间互不关联
- 代理池分为"发布代理"和"监控代理"两个独立池，互不干扰
- 支持批量导入代理、一键测试连通性、自动检测多账号共用 IP 的风险
- 一键自动分配：未绑定代理的账号自动匹配空闲代理

### 数据监控

- 添加任意 Twitter 公开账号进入监控列表
- 自动抓取粉丝数、关注数、推文总数等核心指标
- 查看粉丝数变化趋势图
- 抓取每条推文的浏览量、点赞、转发、评论、书签等互动数据
- 支持"常规推文"和"精选推文"两种维度的数据查看
- 可设置自动刷新频率，也可手动触发即时抓取

---

## 特色与优势

- **全流程打通** — 采集、管理、发布、监控在一个平台内完成，无需多工具切换
- **账号安全隔离** — 账号与代理 IP 一对一绑定，降低多账号被关联封禁的风险
- **发布与监控代理分离** — 操作行为和数据采集使用不同的网络通道，互不影响
- **自动重试机制** — 发布队列自带失败重试和回退，偶发网络问题不会导致内容丢失
- **数据完全自主** — 所有数据本地存储，不依赖第三方云服务

---

## 适用场景

- **MCN 机构海外分发** — 将旗下创作者在 B站的内容搬运到 Twitter/X 进行海外传播
- **批量账号运营** — 同时管理数十个 Twitter 账号，批量发布内容并确保账号安全隔离
- **数据驱动运营** — 持续追踪多个 Twitter 账号的粉丝增长和内容互动数据，辅助运营决策
- **个人创作者出海** — 把国内平台的作品同步到海外，省去手动逐条搬运的麻烦
